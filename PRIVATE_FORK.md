## Privacy

Keep the GitHub repository private. This repository is an independent private copy rather than a public GitHub fork. GitHub and authorized collaborators can access the repository; privacy does not mean anonymity. A future public binary or source release may reveal its open-source origins, and the required license notices must remain.

Feedback submissions are blocked in the Rust backend. Update checks are disabled in the frontend, update endpoints and signing key are empty, update downloads are blocked in the backend, and automatic checks default to off. Upstream Windows signing credentials were removed. Inherited workflows are archived in .github/workflows-disabled and do not run.

Model downloads still contact their real hosting services. SpeakoFlow Mini remains a third-party model with its original name and download coordinates. Cloud providers, website links, and other external tools can make network requests when used. This is not a network anonymity or fully offline guarantee. No public website or announcement was created.

The reserved talvio.invalid hostname is a placeholder, not a registered company website. Configure real support and documentation links before a public release. Set up your own update signing keys, endpoint, feedback service, and CI before enabling them.
